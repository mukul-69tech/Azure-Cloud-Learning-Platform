📄 Project Overview

Student Azure Cloud
Infrastructure Project

This is a college cloud computing project built on Microsoft Azure. It demonstrates how to design, deploy, and secure a multi-tier cloud infrastructure using real Azure services.

The project focuses on how multiple Virtual Machines communicate securely through properly configured VNETs, Subnets, and Network Security Groups — simulating a real-world production environment.

🔐 Security Design

Network Security Configuration

Security rules designed to control access between VMs and enforce least-privilege access.

🔒

Least Privilege Access

DBServerVM is placed in DBSubnet with strict NSG rules. Only WebServerVM is allowed to ping it via ICMP. All other VMs are denied access by default, following the principle of least privilege.

📳

Controlled ICMP Communication

WebServerVM can successfully ping DBServerVM (10.0.1.5). AppServerVM is explicitly blocked from accessing DBServerVM directly through an NSG deny rule, creating a controlled security boundary.

🔐

SSH Secure Access

All VMs are managed securely via SSH using Azure Bastion. Port 22 is not exposed to the internet directly. Bastion provides browser-based access without public IPs on internal VMs.
