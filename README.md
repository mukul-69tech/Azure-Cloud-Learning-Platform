# Azure Cloud Learning Platform

A student-level Azure Cloud Infrastructure project demonstrating:

- Azure Virtual Machines
- VNET and Subnets
- NSG Security Rules
- Bastion SSH Access
- Multi-tier Architecture
- Website Hosting on Azure VM
- VM Communication Restrictions

## Live Website
https://mukul-69tech.github.io/Azure-Cloud-Learning-Platform/

## Architecture
WebServerVM → AppServerVM → DBServerVM

## Security
- Least privilege access
- Restricted ICMP communication
- Secure SSH access
